# Ростелеком Ключ (RTKey) — Home Assistant

**Версия 1.8.1 — Security Hardening** · неофициальная интеграция, не связанная с ПАО «Ростелеком».

## Возможности

- Авторизация по номеру телефона и SMS-коду.
- Обнаружение домофонов и кнопки открытия двери.
- Камеры: видео со звуком и снимки.
- Ограничение запросов и паузы при временной недоступности облачного API.
- Восстановление сущностей камер из локального кеша после перезапуска Home Assistant.

Версия 1.8.0 прошла пользовательские проверки открытия двери, камер, видео со звуком, снимков, перезапуска Home Assistant и кратковременного отключения интернета. **1.8.1 содержит изменения безопасности и требует повторной проверки на реальной системе.**

## Установка / обновление

1. Создайте резервную копию Home Assistant.
2. Скопируйте каталог `custom_components/rtkey` в `/config/custom_components/rtkey`.
3. Перезапустите Home Assistant.
4. При обновлении не удаляйте существующую запись интеграции: настройки авторизации сохраняются.

Для установки как пользовательского репозитория HACS: HACS → три точки → Пользовательские репозитории → URL репозитория → тип «Интеграция». После установки перезапустите Home Assistant и добавьте «Ростелеком Ключ» через «Настройки → Устройства и службы».

## Безопасность

- В исходниках не должно быть реальных JWT, SMS-кодов и паролей.
- Токены авторизации сохраняются Home Assistant в конфигурации записи интеграции. **Никогда не публикуйте** `/config/.storage`, HAR-файлы и диагностические дампы.
- Видеопоток использует временный токен в URL; такой URL нельзя размещать в issue, логах, скриншотах диагностики или чатах.
- Медиаадреса принимаются только с HTTPS-хостов в домене `rt.ru`. При изменении инфраструктуры Ростелекома может потребоваться расширение списка доверенных доменов после проверки.
- Не публикуйте кеш камер: он содержит идентификаторы и названия камер, которые могут раскрывать персональные данные.
- При ответе `Request Rejected` не выполняйте частые повторные запросы; интеграция вводит паузу.

## Диагностика

Если после обновления камеры не открываются, проверьте журнал Home Assistant и наличие доступа через официальное приложение. При ошибке «untrusted request destination» запишите **только доменное имя** сервера, без полного URL и токенов, и создайте issue. Не отключайте проверку адресов без анализа.

## Ограничения

- Неофициальный облачный API может измениться без предупреждения.
- Автоматическое обновление токена авторизации не реализовано.
- Сохранённый кеш восстанавливает метаданные камер, но не временные токены видео и снимков.
- Проверка исходников не гарантирует отсутствие всех уязвимостей; перед публичным релизом рекомендуется проверить установленную 1.8.1.
