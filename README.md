# Ростелеком Ключ (RTKey) для Home Assistant

[![GitHub release](https://img.shields.io/github/v/release/username-andrey/ha-rtkey)](https://github.com/username-andrey/ha-rtkey/releases)
[![GitHub issues](https://img.shields.io/github/issues/username-andrey/ha-rtkey)](https://github.com/username-andrey/ha-rtkey/issues)
[![HACS Custom](https://img.shields.io/badge/HACS-Custom-blue)](https://www.hacs.xyz/)

**RTKey** — пользовательская интеграция сервиса **«Ростелеком Ключ»** с [Home Assistant](https://www.home-assistant.io/). Она позволяет использовать доступные в учётной записи камеры и устройства управления доступом непосредственно в Home Assistant.

> [!IMPORTANT]
> Это неофициальный проект сообщества. Он не разработан, не поддерживается и не одобрен ПАО «Ростелеком». Для работы необходима действующая учётная запись сервиса «Ростелеком Ключ» с доступом к соответствующим устройствам.

## Возможности

- Авторизация с подтверждением по SMS.
- Обнаружение доступных камер и устройств управления доступом, привязанных к учётной записи.
- Просмотр видеопотока камер, включая звук при его наличии в источнике и поддержке клиентом воспроизведения.
- Получение снимков с камер.
- Управление доступными калитками / точками прохода из Home Assistant.
- Работа через интерфейс Home Assistant без необходимости постоянно открывать официальное приложение.

Фактический набор устройств и функций зависит от возможностей учётной записи, оборудования и ответа сервиса Ростелекома.

## Требования

- Работающий Home Assistant с возможностью установки пользовательских интеграций.
- Установленный [HACS](https://www.hacs.xyz/) — для рекомендуемого способа установки.
- Учётная запись «Ростелеком Ключ» с доступом к камерам и/или устройствам управления доступом.
- Возможность получения SMS на номер, связанный с учётной записью.
- Сетевой доступ Home Assistant к сервисам Ростелекома.

**Проверенная версия проекта:** `v1.8.1`. Установка и основные функции были успешно проверены на Home Assistant 2026.9.x. Это не означает гарантированной совместимости со всеми версиями Home Assistant.

## Установка через HACS

1. Откройте **HACS** в Home Assistant.
2. В меню HACS выберите **Пользовательские репозитории** (*Custom repositories*).
3. Укажите адрес репозитория:

   ```text
   https://github.com/username-andrey/ha-rtkey
   ```

4. Выберите тип **Интеграция** (*Integration*) и добавьте репозиторий.
5. Найдите **RTKey / Ростелеком Ключ** и установите последнюю стабильную версию.
6. Перезапустите Home Assistant.
7. Перейдите в **Настройки → Устройства и службы → Добавить интеграцию**, найдите RTKey и следуйте инструкциям настройки.

> Если репозиторий уже добавлен в HACS, повторно добавлять его не требуется.

## Настройка и авторизация

1. Запустите настройку RTKey через интерфейс Home Assistant.
2. Укажите номер телефона, используемый в сервисе «Ростелеком Ключ».
3. Запросите код подтверждения и дождитесь SMS.
4. Введите полученный код в форму настройки.
5. После успешной авторизации проверьте появление доступных устройств и сущностей.

Не передавайте SMS-коды, токены доступа и другие данные авторизации третьим лицам.

## Использование

### Камеры

Камеры, доступные через учётную запись, могут использоваться в интерфейсе Home Assistant для просмотра видео и получения снимков. Наличие звука зависит от видеопотока и способа воспроизведения на конкретном клиенте.

### Управление доступом

Доступные калитки и другие поддерживаемые точки прохода можно управлять через соответствующие сущности Home Assistant.

> [!CAUTION]
> Команды открытия дают физический доступ на территорию. Не публикуйте такие элементы управления в общедоступных панелях и не создавайте автоматизации, которые могут открыть проход без вашего намерения.

## Обновление

Обновления устанавливаются через HACS. После обновления при необходимости перезапустите Home Assistant и проверьте работу камер и устройств управления доступом.

Актуальные версии и примечания к выпускам: [GitHub Releases](https://github.com/username-andrey/ha-rtkey/releases).

## Устранение неполадок

| Симптом | Что проверить |
| --- | --- |
| SMS не приходит | Работу авторизации на официальном сайте/в приложении; доступность SMS; временные ограничения на повторные запросы |
| Ошибка при авторизации | Корректность номера и кода, сетевое подключение, временные сбои сервиса |
| Камеры не отображаются | Доступ к камерам в учётной записи и состояние интеграции |
| Нет видео или звука | Доступность потока, поддержку формата браузером/клиентом, наличие звука в источнике |
| Не работает открытие калитки | Доступность устройства и разрешения учётной записи; сообщения в журнале Home Assistant |
| После обновления интеграция не загружается | Перезапуск Home Assistant, установленную версию и записи журнала |

При временной ошибке авторизации **не отправляйте SMS-запросы многократно подряд**: сервис может ограничивать частоту попыток.

Для диагностики откройте **Настройки → Система → Журналы** в Home Assistant. Перед публикацией журналов удалите из них персональные данные, номера телефонов, токены, SMS-коды и URL видеопотоков с параметрами авторизации.

Сообщить об ошибке: [GitHub Issues](https://github.com/username-andrey/ha-rtkey/issues). Укажите версию RTKey, версию Home Assistant, последовательность действий и обезличенный текст ошибки.

## Безопасность и конфиденциальность

- Используйте интеграцию только со своей учётной записью и устройствами, к которым у вас есть законный доступ.
- Не публикуйте файлы конфигурации, токены, SMS-коды и ссылки на приватные потоки.
- Ограничивайте доступ к панели Home Assistant и включите многофакторную аутентификацию для учётной записи Home Assistant, если она доступна.
- Передавайте сообщения об уязвимостях разработчику приватно, не размещая действующие секреты в публичных Issues.
- Интеграция зависит от внешнего сервиса: изменения API или правил авторизации Ростелекома могут повлиять на её работу.

## Статус проекта

**`v1.8.1` — стабильный выпуск.** На чистой установке подтверждены SMS-авторизация, работа камер и управление калитками. Это функциональная проверка, а не независимый аудит безопасности.

Проект развивается независимо от Ростелекома. Совместимость с будущими изменениями API и Home Assistant не гарантируется.
