# История изменений

## 1.8.1 — Security Hardening (2026-10-13)

- Проверка HTTPS, адреса назначения, порта и отсутствия встроенных учётных данных до отправки секретов.
- Токен авторизации отправляется только на известные API-хосты `keyapis.key.rt.ru` и `household.key.rt.ru`.
- Медиаадреса ограничены доменами `rt.ru` и его поддоменами; перенаправления HTTP по-прежнему запрещены.
- Проверка адреса снимка перед передачей `X-UTOKEN`, в том числе при повторной попытке.
- Убраны значения исключений из журналов интеграции и сообщений об ошибках запуска.
- Ограничен максимальный размер HTTP-ответа (16 МиБ).
- При загрузке устаревшего кеша камер он сразу переписывается без токенов и URL.
- Сохранены механизм видео со звуком, кнопки домофонов, ограничения запросов и паузы после отказов API версии 1.8.0.

## 1.8.0 — Stabilization

- Ограничение запросов, паузы при ошибках защиты API, кеширование метаданных камер, безопасные логи.
